# LSA

## Definition

A **Link State Advertisement (LSA)** is the OSPF unit of topology information — each LSA describes a router, a network segment, a summary route, or an external route and is flooded to build the [[Link State Database]].

## LSA Types (OSPFv2)

| Type | Name | Description |
| --: | --- | --- |
| 1 | Router LSA | Every router's links and interfaces within its area |
| 2 | Network LSA | Generated by DR for a multi-access segment |
| 3 | Network Summary LSA | Inter-area routes (sent by [[ABR]]) |
| 4 | ASBR Summary LSA | Route to an [[ASBR]], sent by ABR |
| 5 | AS-External LSA | External routes redistributed by an ASBR |
| 7 | NSSA External LSA | External routes inside an [[OSPF Area\|NSSA]] (converted to type 5 at the ABR) |

(Opaque types 9/10/11 carry MPLS-TE, OSPFv3 extensions, etc. — know types 1–5, 7 for CCNP.)

## Flooding and Scope

| LSA | Flooding scope |
| --- | --- |
| Type 1, 2 | Area-local only |
| Type 3, 4 | Inter-area (via ABRs) |
| Type 5 | Whole AS (except stub areas) |

## Exam Focus

- **Type 5 is blocked in stub areas** — that is the entire point of [[OSPF Area|Stub areas]].
- **Type 7 → Type 5 translation** happens at the ABR for NSSA external routes.
- Type 4 exists so routers can find the ASBR; a missing Type 4 breaks external route computation.
- Type 2 is generated by the designated router ([[DR BDR]]) — no DR, no Type 2 LSA.
