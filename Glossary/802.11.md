# 802.11

## Definition

**IEEE 802.11** is the WLAN standard family — it defines the **MAC** and **PHY** layers, the **management frames** (beacon, probe, association), and every **amendment** that bumps speed: **a (5 GHz) → b/g (2.4 GHz) → n (MIMO) → ac (Wave 1/2, 5 GHz) → ax (Wi-Fi 6, both bands + OFDMA)**. The exam expects the 802.11 generations, bands, and which features each brought.

## Generations at a Glance

| Amendment | Bands | Headline feature |
| --- | --- | --- |
| 802.11a | 5 GHz | OFDM, up to 54 Mbps |
| 802.11b | 2.4 GHz | Up to 11 Mbps |
| 802.11g | 2.4 GHz | 54 Mbps in 2.4 GHz |
| 802.11n (Wi-Fi 4) | 2.4/5 | MIMO, 40 MHz channels |
| 802.11ac (Wi-Fi 5) | 5 GHz | Wide channels 80–160 MHz, MU-MIMO |
| 802.11ax (Wi-Fi 6) | 2.4/5/6 | OFDMA, higher density/efficiency |

## Exam Focus

- **Match amendment → band → headline feature** — the table question (ac = 5 GHz only, n = both, ax = both + 6 GHz via WiFi 6E).
- **Which mandate**: 5 GHz always = a/ac; 2.4 GHz = b/g/n/ax — "which 802.11 supports 5 GHz?" answers.
- **Management frames**: beacon (broadcast SSID/info), probe (active scan), associate/authenticate — the frame-functions pairing.
- The **6 GHz band** (Wi-Fi 6E) is the newest spectrum — the freshness question.
