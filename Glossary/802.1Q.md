# 802.1Q

## Definition

**IEEE 802.1Q** is THE standard for **VLAN tagging** — a **4-byte tag inserted after the source MAC** marks each frame with its VLAN. It is the only trunking approach on modern Cisco gear (ISL is dead), works over single links, and includes priority bits that feed [[QoS]].

## The 4-Byte Tag

```text
[Dest MAC][Src MAC][802.1Q tag][EtherType][Payload][FCS]
                 ├──────────────┤
                 TPID 0x8100  (16 bits)
                 PCP 3 bits    (priority 0–7 = CoS)
                 DEI 1 bit     (drop eligible)
                 VLAN ID 12 bits (0–4095)
┌ host/tag/native rules ┐
  access ports don't tag; trunks tag all but native
  maximum 4094 usable VLANs (0/4095 reserved)
```

## Exam Focus

- **Tag position and TPID (0x8100) are asked verbatim**; "which header carries CoS for QoS?" → the 802.1Q PCP bits.
- **VLAN ID range 12 bits → 0–4095**; usable up to **4094** (or 4095 on modern platforms).
- **Single tagging only on Cisco** now — ISL is legacy; [[QinQ]] extends 802.1Q for carrier environments.
