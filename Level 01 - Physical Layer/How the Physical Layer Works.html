Power budget basics

Each connector ≈ 0.5 dB loss, each splice ≈ 0.1–0.3 dB, plus fiber attenuation (MMF ≤3.5 dB/km @850 nm; SMF ≤0.4 dB/km @1310 nm). If total loss exceeds receiver sensitivity, the link fails.

One-Minute Summary & Self-Test

Physical Layer in 60 seconds

Media families:  UTP (4 twisted pairs, 100 m, cheap) → STP (shielded, noisy environments, must ground)
                 Fiber SMF (9 µm, laser, 10 km+, yellow jacket) vs MMF (50 µm, VCSEL, 300–550 m, aqua)
                 Wireless (RF, shared medium, 2.4/5/6 GHz, 1/6/11 non-overlapping)

UTP categories:  Cat5 100 MHz → Cat5e (gigabit) → Cat6 (10GBASE-T ≤55 m) → Cat6a (10GBASE-T 100 m) → Cat8 (25/40G ≤30 m)
Auto-MDIX makes straight/crossover irrelevant; 1000BASE-T = FDX only (4 pairs, no HDX mode).

Standards naming: BASE — T=copper, S=short fiber, L=long fiber, E=extended, C=copper twinax, K=backplane
Encoding: 8B/10B (1G) → 64B/66B (10G+) → parallel lanes for 40/100G (SR4/LR4)

Duplex: FDX = simultaneous TX/RX (modern); HDX = CSMA/CD one-at-a-time (hubs, 10/100)
Auto-neg: if one side forced → auto side defaults to HDX (no FLP) → MISMATCH → late collisions.
1G is FDX-only: no HDX fallback possible.

MTU: default 1500 B (L3 payload). Frame = MTU + 18 (untrunked) / +22 (802.1Q).
IPv6 never fragments; PMTUD + ICMPv6 Packet Too Big.
Tunnel overhead: GRE −24 B (1476), PPPoE −8 B (1492), VXLAN −50 B (~1450).

Connectors: RJ-45 (copper), LC (SFP/SFP+ fiber, most common), SC (legacy panels), MPO (QSFP 40/100G parallel)
Transceivers: SFP 1G, SFP+ 10G, SFP28 25G, QSFP+ 40G, QSFP28 100G — SR=850nm MM, LR=1310nm SM
DOM reads laser TX/RX power from the module, not the fiber.

Patch panels: 90 m horizontal + 10 m patch = 100 m budget. Label, LLDP, polarity through fiber panels.
Media conversion: L1 electrical↔optical, transparent to L2 — but fiber has no PoE.
