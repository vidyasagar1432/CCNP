🗃️ Routing Table (RIB) — where traffic should go

The routing table, also called the RIB (Routing Information Base), is the control-plane database holding the best routes to known destination prefixes. Derived from it, the FIB/CEF is what actually forwards packets.

Core idea: RIB decides where traffic should go; FIB/CEF forwards it.

Anatomy of a route entry

O    10.1.1.0/24 [110/20] via 192.0.2.1, 00:12:34, GigabitEthernet0/1
FieldMeaning

[110/20]AD / metric — 110 = AD, 20 = protocol metric
via 192.0.2.1Next-hop IP address
00:12:34Route age

Trap: The bracket is always [AD / metric] — do not reverse them. `110` is the AD; `20` is the OSPF cost.

Route selection — AD first, metric second

Same prefix, different sources→ Compare AD
Same prefix, same protocol→ Compare metric
Equal-cost paths→ ECMP (multiple installed next hops)
Exam rule: AD compares routing sources. Metric compares paths within a routing protocol.
ECMP: a prefix can have multiple installed next hops if paths are equal-cost. With CEF, traffic is normally load-balanced per-flow using hashing.

⚖️ Administrative Distance — who to trust

AD is a Cisco value from 0–255 ranking the trustworthiness of a routing source. When the same prefix comes from multiple sources, the router installs the lowest-AD source. Lower AD = more preferred.

📏 Metrics — the best path within a protocol

A metric measures a path's cost or preference within one routing protocol. Metrics from different protocols are not comparable — across sources, AD decides.

🔁 Recursive Lookup — resolve the next hop

Recursive lookup resolves a route's next-hop address when that next hop is not directly connected. It resolves where the next hop is reachable, not the original destination.

How it works

1. Look up the destination prefix → next hop 10.0.0.1
2. Look up 10.0.0.1 → directly connected Gi0/1
3. Resolved: out Gi0/1 toward 10.0.0.1
192.168.100.0/24   via 10.0.0.1      (destination route)
10.0.0.0/24        directly connected Gi0/1   (next-hop route)

Trap: FIB ≠ adjacency table. The FIB is the Layer-3 forwarding decision; the adjacency table provides the Layer-2 rewrite (next-hop MAC). `show ip cef` = FIB; `show adjacency` = L2 rewrite info.

CEF adjacency types

TypeMeaning
ReceiveTraffic destined to an address owned by the router (handled locally)
Connected / AttachedDirectly connected network
GleanConnected subnet known, specific host adjacency not yet resolved
Next-hopForward toward a resolved next hop
Drop / NullExplicitly discard (Null → null interface)
Glean: the router knows the destination is on a connected subnet but hasn't ARP/ND-resolved the specific host yet. IPv4 uses ARP; IPv6 uses Neighbor Discovery. Glean ≠ missing route.
ECMP + CEF: multiple equal-cost forwarding paths are balanced with hash-based, usually per-flow, load sharing. Hash polarization can concentrate traffic in multi-stage ECMP.

Static routes are manually configured, have AD 1 (connected = 0), and provide predictability with low overhead — but they don't auto-discover alternate paths or reconverge.

🛟 Floating Static — a backup via higher AD

A floating static is a static route configured with an AD higher than the primary so it stays out of the RIB until the primary disappears. Higher AD = lower preference.

Core idea: Normal static AD = 1 → floating static = higher AD → backup route.

Trap: Floating ≠ "link down = backup." It's based on route availability. For failures beyond the next hop, combine with IP SLA + object tracking to withdraw the primary and let the floating static activate.

🧭 Default Route — the catch-all

The default route is the least-specific route, used when no more-specific route matches: IPv4 0.0.0.0/0, IPv6 ::/0. It can be static or dynamically learned/advertised.

LPM always wins over the default

10.10.10.0/24   ← longest match for 10.10.10.5
10.10.0.0/16
10.0.0.0/8
0.0.0.0/0        ← least specific (default)
Trap: The default route is not "always used" and doesn't win by AD. It's selected because it is the least-specific matching prefix when no longer prefix matches. If there's no match and no default, the packet is dropped.

Default route vs default gateway vs gateway of last resort
