# Device-Level Security Hardening (IOS XE)

> **Level 28 · Cisco IOS and IOS XE** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**Device-level security hardening** protects the management plane and platform itself —
not just the data plane. It covers **login/AAA security, role-based access, control-plane
policing (CoPP), SNMP management, and out-of-band/management-plane protection**. The exam
tests AAA models, usernames/roles, management-plane protection, and the principle of least
privilege.

---

## 2. Core Concepts

### 2.1 Authentication, Authorization, Accounting (AAA)

| Component | Function |
|-----------|----------|
| **Authentication** | verify who (login) |
| **Authorization** | what they may do |
| **Accounting** | log what they did |
| Server | TACACS+ or RADIUS |

- **TACACS+ (TCP 49)** separates auth/authorization/accounting and encrypts all three;
  **RADIUS (UDP 1812/1813)** combines them.

### 2.2 AAA configuration (model)

```text
aaa new-model
aaa authentication login default group tacacs+ local
aaa authorization exec default group tacacs+ local
aaa accounting exec default start-stop group tacacs+
!
username admin privilege 15 secret StrongPass
tacacs-server host 192.168.1.10 key SecretKey
```

| Command | Purpose |
|---------|---------|
| `aaa new-model` | enable AAA |
| `aaa authentication login` | login method |
| `aaa authorization exec` | privilege per session |
| `aaa accounting` | audit trail |
| `username ... privilege` | local user + level |

### 2.3 Local users, privileges & roles

| Item | Detail |
|------|--------|
| `username admin privilege 15` | highest level local user |
| `privilege level` (0–15) | granular command access |
| `role` / `parser view` | role-based access |
| `enable secret` | privileged password (hashed) |

- Use **least privilege**: give users only the levels/roles they need.

### 2.4 Management plane / control plane protection

| Control | Purpose |
|---------|---------|
| **CoPP (control-plane policing / protection)** | rate-limit control-plane traffic |
| **Management-plane protection (MPP)** | restrict mgmt protocols to mgmt interfaces |
| SSH vs Telnet | encrypt management sessions |
| ACL on vty | limit who can reach line vty |

- Apply **CoPP** to stop control-plane DoS; **MPP** restricts management-plane access.

### 2.5 CoPP configuration

```text
class-map match-any TELNET-CP
 match protocol telnet
!
policy-map COPP
 class TELNET-CP
  police cir 8000 bc 1500
   conform-action transmit
   exceed-action drop
!
control-plane
 service-policy input COPP
```

| Command | Purpose |
|---------|---------|
| `control-plane` | enter control plane |
| `service-policy input` | apply CoPP |
| `police cir` | limit rate |

### 2.6 Other hardening measures

| Measure | Detail |
|---------|--------|
| SSH only + `transport input ssh` | disable Telnet |
| SNMPv3 | encrypted, authenticated |
| `login block-for` | brute-force protection |
| `no ip http server` | disable unencrypted HTTP |
| NTP authentication | prevent spoofing |
| Logging / NTP / identity | visibility |

## 3. Configuration / Commands

```text
line vty 0 4
 transport input ssh
 login local
!
ip ssh version 2
username admin privilege 15 secret StrongPass
enable secret HashedSecret
!
no ip http server
snmp-server group MGT v3 priv
control-plane
 service-policy input COPP
!
show aaa
show control-plane
show ip ssh
```

## 5. Exam Traps

- **TACACS+ separates AAA and encrypts everything; RADIUS combines auth/accounting and encrypts only the password.**
- Use **SSH, not Telnet** — Telnet is cleartext.
- **CoPP protects the control plane**; MPP protects the management plane.
- **`enable secret` is hashed; `enable password`** is weak/cleartext-capable.
- Enforce **least privilege** with privilege levels and roles.

## 7. One-Minute Mental Model

**Hardening** = secure the box itself: use **AAA** (TACACS+ for full separation, RADIUS
elsewhere), give **local users least-privilege levels/roles** with `enable secret`, manage
over **SSH not Telnet**, and protect the **control plane with CoPP** (`control-plane` +
`service-policy input`) plus the **management plane with MPP**. Kill unencrypted HTTP,
use **SNMPv3**, and you've closed the classic device-level holes the exam loves to test.
