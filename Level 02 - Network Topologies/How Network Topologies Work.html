🏢 Spine-Leaf (Clos) Architecture

Modern data-center fabric: every leaf ↔ every spine. No leaf-leaf or spine-spine links. All uplinks ECMP — no STP blocking.

Scaling Rule: Add spines → more paths per leaf (capacity). Add leaves → more endpoints (total bandwidth). Spine count = ECMP paths = bandwidth per leaf.
