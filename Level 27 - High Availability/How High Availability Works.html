🛡️ High Availability — the whole picture

HA is layered: each layer covers a different failure mode. SSO/NSF = the brain, redundant supervisors = the chassis, EtherChannel = links, HSRP/VRRP/GLBP = gateway, and routing/ECMP = paths.

The layered redundancy model

Brain

SSO, NSF, ISSU

Links

EtherChannel / LAG

Gateway

HSRP / VRRP / GLBP

Best practice #1: NO single point of failure on any critical path. And test it — untested redundancy isn't redundancy.

🔄 SSO — Stateful Switchover

Keeps control-plane state synced between active & standby supervisors so a switchover causes no forwarding interruption.

🚚 NSF — Non-Stop Forwarding

Continues forwarding while the control plane recovers during a switchover. CEF/FIB independent of the control plane keeps packets flowing.

NSF + SSO (the classic pair)

SSO

preserves control-plane state

NSF

continues forwarding

Peers must be NSF-aware (graceful restart) to hold state instead of flapping routes. OSPF `nsf`; BGP `bgp graceful-restart`.
redundancy
 mode sso
!
router ospf 1
 nsf
!
router bgp 65000
 bgp graceful-restart

🔗 Link Redundancy — EtherChannel

Bundle multiple physical links into one logical port-channel to scale bandwidth, avoid STP blocking, and survive link failure.

Protocol picker (the core contrast)

LACP
IEEE standard · active/passive
PAgP
Cisco-proprietary · desirable/auto
Static
mode on · no negotiation
{{ linkVerdict.text }}
Hash (src/dst MAC/IP/port) picks the member per flow so each flow stays in-order. Members must match speed/duplex. vPC/M-LAG = active-active across two switches.

🚪 Gateway Redundancy — HSRP · VRRP · GLBP

Keep the default gateway available by sharing a virtual IP among routers. Hosts point at the virtual IP, not one router.

Protocol picker (memorize)

HSRP
Cisco · Active/Standby · UDP 1985
VRRP
IETF · Master/Backup · 112
GLBP
load-balanced · AVG/AVF
{{ gwVerdict.text }}
HSRP/VRRP = active-passive; GLBP = active-active load sharing. Virtual MAC: HSRP 0c07.acXX, VRRP 0000.5e0001XX. Election: higher priority, tie → higher IP. Preempt to take over.
