🕵️ Dynamic ARP Inspection (DAI)

Layer 2 protection against ARP spoofing/poisoning. Enabled per VLAN; interfaces are untrusted by default. Validates ARP against DHCP Snooping bindings (or an ARP ACL for static devices).

How it works

1 DHCP Snooping builds IP↔MAC bindings
2 enable DAI per VLAN
3 trust infrastructure ports
4 endpoints stay untrusted
5 DAI intercepts ARP, validates

Validation options

src-mac

Ethernet src = ARP sender MAC

dst-mac

destination MAC info

ip

ARP IP fields consistency

Trap: DAI = ARP protection, NOT IP protection. Static-IP devices need an ARP ACL (no DHCP binding). Trusted ports bypass inspection — only trust infrastructure.

🧠 CoPP — Control Plane Policing

Protects the device CPU / control plane using QoS policing. Chain: ACL → class-map → policy-map → applied under control-plane.

Network planes

Data plane

forwards transit traffic (CEF)

Control plane

routing protocols, CPU processing

Management plane

SSH, SNMP, HTTPS, Syslog

ip access-list extended COPP-MGMT
 permit tcp any host 192.0.2.1 eq 22
class-map match-any COPP-MGMT-CLASS
 match access-group name COPP-MGMT
policy-map COPP-POLICY
 class COPP-MGMT-CLASS
  police 512000 conform-action transmit exceed-action drop
 class class-default
  police 8000 conform-action transmit exceed-action drop
control-plane
 service-policy input COPP-POLICY
Traps: CoPP is not an interface ACL — it is applied under control-plane. Over-policing routing protocols → adjacency loss; forgetting to classify management traffic → management lockout. show policy-map control-plane is the key verification.
