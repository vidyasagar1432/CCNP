🛠️ Layer-by-Layer Troubleshooting

This is the biggest exam use of the model. Isolate problems layer by layer.

Layer Isolation Flow

L1 Physical Link lights, duplex/speed errors, CRC
L2 Data Link MAC table, VLAN, STP interaction
L3 Network IP route, longest-prefix match
L4 Transport Port reachability (telnet port)
L7 Application Service, protocol format

Commands by Layer

L1 show interfaces | include (Duplex|Speed|Error|CRC)
L2 show mac address-table
L3 ping <ip> · show ip route
L4 telnet <ip> <port>
L7 curl http://<host>
Classic pattern: "Works for some, not others" + "ping OK but telnet fails" → think L4 ports / L7, not L1-L3.
