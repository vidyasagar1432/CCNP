🔗 PPP — Point-to-Point Protocol

The classic point-to-point WAN protocol that succeeded HDLC with authentication, multilink, and LCP/NCP negotiation. PPPoE rides on it.

🌐 PPPoE — PPP over Ethernet

Carries PPP sessions over Ethernet — the standard for DSL/broadband. Discovery sets up the session, then LCP/CHAP/IPCP run as usual.

Discovery (PADx) — the exam favorite

PADI client broadcast (Initiation)
PADO server offer
PADR client requests
PADS session established
PADI → PADO → PADR → PADS = session creation. The access concentrator issues the session ID.

After discovery

PhaseProtocol
Link configLCP
AuthCHAP/PAP
IP addressingIPCP
DataPPP frames

The MTU trap

MTU 1492 on the link — the 8-byte PPPoE header reduces the payload from 1500.

📶 Broadband & LTE

Cheap, everywhere, but asymmetric, shared, best-effort — the classic secondary/DIA link or SD-WAN transport, not an SLA-committed primary MPLS.

Broadband types

DSL

phone lines · ADSL/VDSL

Cable

coax · shared

Fiber

GPON/EPON · high speed

LTE

cellular · SIM + APN

Fiber = fastest/most symmetric; DSL/cable = asymmetric (down > up); broadband = best-effort with no SLA.

☁️ SD-WAN — overlay over any transport

Cisco SD-WAN (Viptela) builds a secure overlay over any transport (MPLS, broadband, LTE) with DTLS/IPsec tunnels between edge routers. A controller cluster manages policies and routing centrally.

Underlay vs overlay

Underlay

physical WAN: MPLS/broadband/LTE

Overlay

secure tunnels, OMP control, centralized policy

SD-WAN decouples services from the physical WAN — any transport works.

The four components (memorize)

vEdge/cEdge

WAN edge routers (data)

vSmart

control + policy (OMP)

vManage

management plane

vBond

orchestration / onboarding

vBond authenticates/onboards; vSmart controls; vManage manages; edges carry traffic.

OMP (Overlay Management Protocol)

Control protocol running edge ↔ vSmart, carrying routes, TLOCs, policies. OMP replaces BGP/IGP in the overlay.

Key features

Transport-independent

any link

App-aware routing

SLA-based path choice

Centralized policy

pushed from vSmart

Security

DTLS/IPsec tunnels

App-aware routing + SLA is the SD-WAN killer feature — cheaper, more reliable, centrally managed.
