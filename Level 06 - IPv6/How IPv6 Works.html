🧭 IPv6 Addressing — 128 bits, 8 hextets

IPv6 uses a 128-bit address — roughly 3.4 × 1038 addresses. Written as eight groups of four hex digits (hextets), it eliminates broadcast and makes IPv4 NAT unnecessary for most designs.

/64 rule

Every LAN is a /64 — mandatory for SLAAC and ND optimizations. A /48 site yields 65,536 /64 subnets.

🔗 Link-Local (fe80::/10)

Automatically configured on every IPv6 interface — mandatory, non-routable, and the basis for ND, SLAAC, routing adjacencies, and the default gateway.

The zone (%notation)

Because fe80:: is identical on every host/interface, you must say which interface:

  • Linux/macOS: ping6 fe80::1%eth0
  • Windows: ping fe80::1%5
Trap: fe80 is not "IPv6 APIPA" — it's normal and deliberate. Zone % is significant to disambiguate interfaces.

MLD (Multicast Listener Discovery)

IPv6's IGMP equivalent: MLDv1 (like IGMPv2) / MLDv2 (source filtering, supports SSM). Switches use MLD snooping to forward to interested ports.

Trap: no IPv6 broadcast exists. ff02::1 is all nodes — a multicast group, not a broadcast. Solicited-node multicast ff02::1:ff00:0/104 powers ND.

⚙️ SLAAC & DHCPv6

SLAAC (Stateless Address Autoconfiguration) lets a host build its own GUA from a Router Advertisement — no server. DHCPv6 adds stateful assignment and options.

SLAAC — the steps a host runs

1. Generate link-local (EUI-64/random)
2. RS → ff02::2 (all routers)
3. Receive RA (prefix + flags + lifetime)
4. Build GUA = prefix + interface ID
5. DAD (NS to solicited-node) before use

🖥️ ICMPv6

IPv6's control protocol — carries error reporting, echo, plus ND (133–137) and MLD (130–132) as submodules. Without PMTUD, IPv6 breaks across MTU limits.

Message classes

ClassTypesPurpose
Error1 · 2 · 3 · 4dest unreachable · PTB · time exceeded · param
Informational128 / 129Echo Request / Reply (ping6)
ND submodule133–137RS RA NS NA Redirect
MLD submodule130–132query / report / done

PMTUD — "routers never fragment"

1. Sender sends a large packet
2. Router whose link MTU is too small sends ICMPv6 Type 2 (Packet Too Big) with the link MTU
3. Sender re-emits with a smaller packet
If PTB is filtered → big packets silently black-hole (MTU black hole). Allow ICMPv6 Type 2, plus ND (133–136) and MLD (130–132) through ACLs, or IPv6 breaks even with forwarding on.

30hop limit exceeded → traceroute6

v4 vs v6: routers may fragment (v4) vs only sender (v6/PTB). Echo is 128/129 (not 8/0). ND lives in ICMPv6 — never answer "ARP".

OSPFv3 vs OSPFv2 notable deltas

  • LSAs no longer carry IPv6 addresses → moved to Type 9 (Intra-Area-Prefix); Type 8 (Link-Local) is new.
  • Neighbors identified by link-local, not GUA.
  • Interface cost default is 1 for any speed (unlike v2's 108/BW).
  • OSPFv3 can also carry IPv4 via address-family — not IPv6-only.

EIGRP IPv6 key facts

  • No network statements in classic mode — interfaces / AF enable it (named mode may use network).
  • Still requires a router-id; same composite metric, DUAL, timers.
  • Multicast is ff02::A, not 224.0.0.10.

Redistribution (Level 13) between IPv6 protocols still requires seed metrics, just like IPv4. OSPFv3 ↔ EIGRP IPv6 ↔ BGP all support redistribution.
