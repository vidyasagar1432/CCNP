CCNP exam rule: Switch = forwards the existing Ethernet frame (MACs unchanged). Router = removes incoming L2 header, creates a new L2 header (MACs change per segment). IPv4 resolves via ARP, IPv6 via Neighbor Discovery.

🗄️ CAM / MAC Address Table

The Layer 2 forwarding database. Lookup key = MAC + VLAN → switch port.

VLANMAC AddressTypePort
{{ e.vlan }} {{ e.mac }} {{ e.type }} {{ e.port }}
Dynamic vs Static: Dynamic entries are learned automatically from the Source MAC and age out (Cisco default ≈ 300s / 5 min). Static entries are manually configured and don't age like dynamic entries. Same MAC can legitimately exist in different VLANs.

CAM vs TCAM

CAM
Exact-match lookups — MAC address forwarding.
TCAM
Ternary (0/1/X don't-care) — routing, ACLs, QoS, policy.
Mental model: ARP table = IPv4 → MAC. CAM/MAC table = MAC + VLAN → switch port. Combining both locates an IPv4 host's switch port.

📇 ARP — Address Resolution Protocol

Resolves IPv4 → MAC for the next hop. ARP is carried directly inside Ethernet frames (EtherType 0x0806), NOT inside IP.

📢
ARP Request (Broadcast) → FF:FF:FF:FF:FF:FF
"Who has 10.1.1.20? Tell 10.1.1.10"
📨
ARP Reply (Unicast) → Requester's MAC
"10.1.1.20 is at AA:BB:CC:DD:EE:FF"
🌐
Then: Ethernet Data → Dest MAC = Host B's MAC
Frame carries IP to the learned MAC
Same subnet: ARP for destination host. Different subnet: ARP for next-hop / default gateway (NOT the remote host). Remote destinations resolve the next hop, then the router routes.
