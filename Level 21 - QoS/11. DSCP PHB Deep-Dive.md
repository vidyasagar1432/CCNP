# DSCP / PHB Deep-Dive (EF, AF, CS)

> **Level 21 · QoS** — CCNP Enterprise (ENCOR 350-401)

---

## 1. Overview

**DSCP (Differentiated Services Code Point)** is the 6-bit L3 field that selects a **PHB
(Per-Hop Behavior)** per router. The key PHB classes are **EF** (expedited forwarding,
voice), **AF** (assured forwarding, with drop precedences), and **CS** (class selector,
backward-compatible with IP precedence). The exam tests the DSCP values, AF drop levels,
and which PHB maps to which traffic.

---

## 2. Core Concepts

### 2.1 DSCP field structure

| Field | Bits | Purpose |
|-------|------|---------|
| DSCP | 6 | PHB selector |
| ECN | 2 | congestion notification |
| Total ToS | 8 | DSCP + ECN |

- DSCP (6 bits) = up to **64 values**; the remaining 2 ToS bits are ECN.

### 2.2 The three PHB families

| PHB | DSCP values | Use |
|-----|-------------|-----|
| **EF** | 46 (0x2E, 101110) | voice, low latency/jitter |
| **AF** (assured forwarding) | AF1x–AF4x | video, data with drop classes |
| **CS** (class selector) | CS0–CS7 (0–56 multiples of 8) | legacy precedence, control |

- **EF = voice**; **AF = video/data**; **CS = class-selector/control**.

### 2.3 EF in detail

| Item | Detail |
|------|--------|
| Value | **46** |
| Binary | 101110 |
| Meaning | single expedited class, no drop precedences |
| Typical | voice RTP |
| Queue | LLQ priority |

- EF is a **single** PHB value (46) with no sub-classes.

### 2.4 AF classes and drop precedence

| Class | DSCP values (drop x1/x2/x3) |
|-------|------------------------------|
| AF1x | 10 / 12 / 14 |
| AF2x | 18 / 20 / 22 |
| AF3x | 26 / 28 / 30 |
| AF4x | 34 / 36 / 38 |

| Drop precedence | Meaning |
|-----------------|---------|
| x1 (low) | lowest drop probability |
| x2 (medium) | medium |
| x3 (high) | highest drop probability |

- Within an AF class, the **third digit (1/2/3) = drop precedence**; the class number
  (1–4) = queue. **Lower drop number survives longer** (e.g., AF41 lives longer than AF43).

### 2.5 CS values (class selector)

| CS | DSCP | Legacy Precedence |
|----|------|-------------------|
| CS0 | 0 | 0 (best effort) |
| CS1 | 8 | 1 |
| CS2 | 16 | 2 |
| CS3 | 24 | 3 |
| CS4 | 32 | 4 |
| CS5 | 40 | 5 |
| CS6 | 48 | 6 (routing/control) |
| CS7 | 56 | 7 |

- **CSx = DSCP x*8** and maps directly to IP precedence; **CS6 (48)** is the network
  control / routing DSCP, **CS5 (40)** is common for EF-adjacent marking.

### 2.6 Common DSCP quick map

| DSCP | Value | Use |
|------|-------|-----|
| EF | 46 | voice |
| AF41 | 34 | video conferencing |
| AF31 | 26 | video streaming |
| AF21 | 18 | signaling/OAM |
| CS6 | 48 | routing control |
| CS0 / BE | 0 | default best effort |

## 4. Exam Traps

- **EF is exactly 46** — a single value, no precedences.
- **AF = class(1–4) + drop(1–3)**: AF41 < AF43 in survival; lower drop number drops less.
- **CSx = x*8** (CS6 = 48), backward-compatible with IP precedence.
- ECN uses 2 bits; **DSCP only 6** of the 8 ToS bits.
- Voice = **EF → LLQ**; video/data = **AF → CBWFQ/WRED**.

## 6. One-Minute Mental Model

**DSCP** is the 6-bit ticket each packet carries (the other 2 bits are ECN) selecting a
**PHB**. **EF (46)** = one strict voice class → LLQ. **AFxy** = class 1–4 with drop
precedence 1–3 (lower = survives) → CBWFQ/WRED. **CSx = x*8** mirrors IP precedence, with
**CS6 (48)** for control. Match DSCP once at the edge, trust it in the core, and queue by
PHB.
