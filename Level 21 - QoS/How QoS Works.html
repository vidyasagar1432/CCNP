🎛️ QoS — the whole picture

Quality of Service gives different traffic different treatment. The flow: Classify → Mark → (Police/Shape) → Queue → Drop (WRED). Two architectures: DiffServ (scalable, per-class) and IntServ (per-flow, RSVP).

The golden rule: mark once at the edge, trust in the core. The edge classifies & sets DSCP; the core reads DSCP and applies the PHB (queue/WRED) — never re-marks.

📚 Queuing — CBWFQ & LLQ

Decides the order packets leave a congested interface. Modern answer: CBWFQ (per-class shares) + LLQ (strict priority for voice).

Mechanism map

MechanismBehaviorUse
FIFOfirst in, first outno QoS
WFQper-flow fairdefault legacy
PQstrict prioritystarvation risk
CBWFQper-class bandwidthmodern default
LLQpriority + CBWFQvoice

priority vs bandwidth (the trap)

priority — LLQ

strict-priority, served first, POLICED to the value

bandwidth — CBWFQ

guaranteed weighted share, not strict priority

LLQ's priority class MUST be policed to prevent starving lower classes — that's the difference from plain PQ.
policy-map WAN-EDGE
 class VOICE
  priority 128          ! LLQ - strict, policed
 class VIDEO
  bandwidth 1000        ! CBWFQ guaranteed share
 class DATA
  bandwidth 2000
 class class-default
  fair-queue
interface GigabitEthernet0/1

🛑 Congestion Avoidance — WRED

Drops packets before a queue overflows to prevent tail drop and TCP global synchronization.

The tail-drop problem

Dropping at the tail hurts voice and causes synchronized TCP slow-downs (all flows back off together, then burst together).

WRED thresholds (min → max → full)

Below min

normal — no drop

min → max

random drop rate ↑ as depth grows

Above max

full — drop all

Weighted = per-class drop profile

ClassDrop profile
Voice (EF)no drop / highest min
Video (AF)moderate
Best effortaggressive
Trap: tail drop → TCP global sync, and WRED fixes both. Thresholds min → max → full. ECN marks instead of drops (TCP-friendly). Applies at congested egress.
policy-map AVOID
 class AF31
  bandwidth 1000
  random-detect dscp-based
interface Gi0/1
 service-policy output AVOID

show queueing random-detect

🌐 DiffServ — Differentiated Services

Each packet carries its own class in the DSCP field; each router applies a PHB. No signaling, no reservations — scalable, the de-facto model.

DSCP and PHB

FieldBitsPurpose
DSCP6packet class
ECN2congestion marks
PHB—treatment per class

The PHB classes

PHBDSCPUse
EF46voice (low latency)
AF4x34/36/38video conf
AF3x26/28/30video stream
AF2x18/20/22signaling/OAM
AF1x10/12/14bulk
CSx0–56class selector / control
AF = assured forwarding with 3 drop precedences (x1 low, x2 medium, x3 high). Lower drop number = better survival (AF41 outlives AF43).

Network zones

Edge

classify + mark

Core

trust + PHB (queue/WRED)

Provider

honor DSCP / contract

policy-map DIFFSERV
 class VOICE
  priority 128
 class VIDEO
  bandwidth 1000
  random-detect dscp-based
 class DATA
  bandwidth 2000
Trap: DiffServ = DSCP + PHB, no signaling, per-class, statistical. EF → LLQ; AF → bandwidth + WRED; BE → default. Mark at edge, trust in core.

🎟️ IntServ — Integrated Services (RSVP)

Per-flow hard QoS guarantees using RSVP to reserve bandwidth end-to-end before traffic flows.

The IntServ model

Flow

per session/app

Reservation

RSVP PATH/RESV

State

per-flow on EVERY router

Every router holds per-flow state — that's why it doesn't scale to large networks.

RSVP flow

1 PATH: sender → receiver (announce requirements)
2 RESV: receiver → sender (reserve resources)
3 Admission on each hop: accept / reject

🎚️ DSCP & PHB Deep-Dive

DSCP is the 6-bit L3 field selecting a PHB (the other 2 ToS bits are ECN). Three PHB families: EF, AF, CS.

DSCP field structure

[ DSCP · 6 bits ][ ECN · 2 bits ] — 8-bit ToS byte. DSCP = up to 64 values.

AF drop precedence calculator

{{ afVerdict.text }}

CS selector (CSx = x*8)

{{ csVerdict.text }}

The three PHB families

EF = 46

voice · single value, no precedences → LLQ

AFx.y

video/data · class 1-4 + drop 1-3 → CBWFQ/WRED

CSx = x*8

class selector · legacy precedence · CS6=48 control

class-map match-any VOICE
 match dscp ef
class-map match-any VIDEO
 match dscp af41 af31
policy-map DSCP-PHB
 class VOICE
  priority 128
 class VIDEO
  bandwidth 1000
Trap: EF is exactly 46 — single value. AF = class(1-4) + drop(1-3): AF41 survives longer than AF43. CSx = x*8 (CS6 = 48). ECN uses 2 bits; DSCP only 6.
